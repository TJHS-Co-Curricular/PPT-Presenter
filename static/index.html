设置

全局快捷键 PowerPoint 在前台放映时也有效。点一下输入框再按键；Backspace 清除

设了全局快捷键的按键会被控制台独占，其他程序收不到，所以请用放映时用不到的键（例如 F8–F11 或 Ctrl+Alt+字母；F12 被 Windows 保留，不能用）。
控制台窗口内的按键：→ / 空格 / PageDown 下一页 · ← / PageUp 上一页 · Home 第一页 · End 最后一页
B 黑屏 · W 白屏 · Esc 结束放映 · Enter = GO · S 把选中的设为待命 · ↑↓ 在节目单中移动选择
节目单：单击 = 查看页面 · 双击或 ▶ = 立刻放映 · ★ = 设为待命
其他设置（启动时预加载、缩略图大小）在程序旁边的 config.json 里。
