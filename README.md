# PPT 控制台

在一个窗口里集中控制多份 PowerPoint 和视频，适合典礼、晚会这类“按节目单逐个播放”的场合。纯本机运行，不对外开放。

## 需要
- Windows 10 / 11 + Microsoft PowerPoint（WPS 演示也会尝试连接）
- 系统自带的 Microsoft Edge WebView2（Windows 10/11 基本都已装好；如果窗口打不开，到微软官网下载 “WebView2 Runtime” 安装）
- 可选：[VLC](https://www.videolan.org/)。装了 VLC 时视频会全屏播放，也能在控制台上按“停止”；没装就用系统默认播放器

## 打包成 exe
双击 `build.bat`（第一次需要网络来安装依赖）。完成后会自动打开 `dist` 文件夹，里面的 `PPT-Presenter-VX.Y.exe` 就是成品，只需要这一个文件，电脑上不用装 Python。

版本号来自 `CHANGELOG.md` 最上面的 `## [X.Y]` 标题（控制台右上角也会显示）。每次改动请先在 CHANGELOG 最上面加一个新版本再打包。

- 把 exe 放进放 PPT 的文件夹里双击，就会直接读取那个文件夹；也可以放在别处，再到 **设置** 里选文件夹。
- `config.json`、缩略图缓存 `.cache`、日志 `ppt-presenter.log` 会生成在 exe 旁边。
- 同时只能开一个控制台；再双击一次只会把已开的窗口叫到前面。
- 关掉控制台窗口 = 程序结束（PowerPoint 和正在放映的 PPT 不会被关掉）。
- 少数杀毒软件会误报 PyInstaller 打包的 exe，加入白名单即可。

开发 / 调试时也可以双击 `start.bat` 直接用 Python 运行（会多一个显示日志的命令行窗口）。
代码结构和开发说明见 `CLAUDE.md`（后端在 `presenter/` 包里，按功能分模块）。

## 用法
| 操作 | 方式 |
|---|---|
| 查看某份 PPT 的所有页面 | 在节目单里单击它 |
| 立刻放映 | 点 ▶ 或双击 |
| 从某一页开始放 | 单击下方的缩略图 |
| 设为待命 | 点 ★（或选中后按 S） |
| **GO**：放映待命节目，并自动把下一个节目设为待命 | 点 GO 或按 Enter |
| **播完自动接**：PPT 放到最后一页再按下一页，自动开始待命的节目 | 控制台按钮、F10 快捷键、翻页笔都有效（设置里可关） |
| 上一页 / 下一页 | ← / →、空格、PageUp / PageDown |
| **大会背景** / **礼成**：放映编号 0 的 PPT 的第 1 / 第 2 页（待命不变） | W / B，或底部按钮 |
| **完全关闭**：把这个环节的节目从 PowerPoint 里关掉、释放内存（编号 0 不能关） | 待命左边的 ⏏ 按钮 |
| 结束放映 | Esc |
| 窗口置顶 | 右上角 📌 |

以上按键只在控制台窗口在前台时有效。

### 全局快捷键（PowerPoint 在前台时也有效）
| 默认按键 | 动作 |
|---|---|
| F8 | GO |
| F10 / F9 | 下一页 / 上一页 |
| F7 | 大会背景 |
| F11 | 礼成 |
| Ctrl+Alt+P | 把控制台窗口叫到最前面 |

F12 被 Windows 保留给调试器，任何程序都不能把它设成全局快捷键。

在 **设置** 里可以改：点一下输入框，按下想用的组合键即可（Backspace 清除）。结束放映默认没设，需要可以自己加。
设了全局快捷键的按键会被控制台独占，其他程序收不到，所以请用放映时用不到的键。翻页笔一般发的是 PageUp / PageDown / B / Esc，这些不要设成全局快捷键，直接让 PowerPoint 处理就行，控制台会自动同步页码。

### 编号 0：大会背景（固定，不能关闭）
- 节目单里编号为 **0** 的 PPT 是大会背景：**第 1 页 = 大会背景**，**第 2 页 = 礼成**。底部的“大会背景”“礼成”按钮（或 W / B、F7 / F11）随时切过去，待命不变。
- 它永远不能被关闭：“完全关闭”和“关闭文件”都会拒绝，节目单里会标 🔒。

### 完全关闭
- 一个环节结束后按待命左边的 **⏏ 完全关闭**，把刚播完的节目从 PowerPoint 里关掉，节省内存（大文件、视频很占资源）。按钮上会显示要关的是哪一个。
- 如果它还在投影上，会先切到大会背景再关，投影上不会露出桌面；如果你已经切到大会背景，关的就是刚才播过的那个节目。视频则会停止播放。
- 关掉的节目以后照样可以再放（只是要重新打开，大文件会等几秒）。

### 待命和自动接续
- 开始任何一个节目（GO、▶、双击都一样），它后面的那个节目就自动变成待命；想跳过某个节目，用 ★ 手动改待命即可。
- PPT 放完最后一页再按下一页，PowerPoint 会进入“放映结束”黑屏，控制台一看到这个状态就立刻开始待命的节目，所以投影上只会闪一下黑屏。
- 节目单播完（没有待命）时，就照常停在结尾黑屏。
- 待命会记在 config.json 里，重开程序后还在。

### 其他
- **预加载全部**（典礼开始前做一次）：打开全部 PPT、为每一页生成缩略图、读取演讲者备注，全部存进 `.cache`。之后放映翻页不用再临时读取，延迟最低；下次启动已做好的会跳过。**预加载期间界面会被锁住、不能放映或翻页**，可以随时取消。正在放映时不能开始预加载。
- 切换到另一份 PPT 时，会先开新的放映再结束旧的，所以投影上不会闪出桌面（可在设置里关掉自动结束）。
- 节目单按文件名开头的编号排序（0、1、5.1-5.3、5.4 … 10、11、12），没有编号的文件放在最后。
- 在 PowerPoint 里手动开的放映也会被接管显示。

## config.json（第一次运行后自动生成）
| 键 | 说明 |
|---|---|
| `folder` | PPT 所在文件夹（留空 = exe 所在文件夹） |
| `end_previous_show` | 切换 PPT 时是否自动结束上一份的放映 |
| `auto_advance` | PPT 放到结尾时自动开始待命的节目（默认开） |
| `preload_on_start` | 启动时自动预加载全部 PPT |
| `thumb_width` | 缩略图宽度（像素） |
| `prefetch_thumbs` | 没在放映时自动预先生成缩略图（默认开） |
| `open_with_window` | 带窗口打开 PPT 再最小化（默认开；内嵌字体、平滑切换需要它） |
| `work_during_show` | 放映中也生成缩略图 / 读备注（默认关：会打断动画，请改用预加载） |
| `window_on_top` / `window_size` | 窗口置顶、窗口大小（程序会自动记住） |
| `hotkeys` | 全局快捷键，例如 `"go": "F8"`、`"white": "Ctrl+Alt+W"`；空字符串 = 不用 |
| `debug_console` | 启动时自动打开调试窗口 |
| `port` | 内部通信端口，0 = 自动（只在本机 127.0.0.1，外部连不进来） |

## 性能说明
- PowerPoint 一次只能处理一个外部命令，所以对 PowerPoint 的操作都排在一个专用线程里：翻页、放映优先，缩略图其次，预加载最后。
- PowerPoint 正在打开大文件或开始放映时会回复“忙碌”，控制台会自动等它（最多 30 秒）再执行，不会报错。顶部状态会显示它在忙什么。
- 控制台每 0.1 秒读一次 PowerPoint 的页码，一有变化就马上更新界面，所以在 PowerPoint 里直接按键或用翻页笔，界面也会同步。
- 全局快捷键的翻页、大会背景 / 礼成直接在后台执行，不经过界面，是最快的路径。
- 放映中会预先生成当前页和后面几页的缩略图；没在放映时，空闲的 PowerPoint 会把已加载 PPT 的缩略图全部做好。

## 调试窗口
点右上角 **🐞 调试**，会另开一个命令行窗口实时显示运行日志：每个操作花了多少毫秒、PowerPoint 忙碌重试、页码变化、快捷键、错误（红色）。
这个窗口是独立的，随时关掉都不影响控制台和放映；控制台关闭时它也会自动关掉。
想每次启动都自动打开：在 `config.json` 里设 `"debug_console": true`，或用 `PPT-Presenter-VX.Y.exe --debug` 启动（可以做一个带参数的快捷方式）。
同样的内容也一直写在 exe 旁边的 `ppt-presenter.log` 里（超过 5 MB 会自动改名为 `.log.old`）。

## 注意
- PPT 会在 PowerPoint 里以“只读、最小化窗口”的方式打开（任务栏上会看到它们），这样内嵌字体和平滑切换才正常。
- 预加载结果会列出这台电脑**没安装、也没内嵌**的字体，放映时这些字会被替换：请安装字体，或在 PowerPoint 里“另存为 → 工具 → 保存选项 → 将字体嵌入文件”。
- PPT 以**只读**方式在后台打开，不会改动原文件，也不会产生 `~$` 锁文件。
- 如果 PowerPoint 弹出对话框（例如“受保护的视图”或“修复”），控制会卡住，需要到电脑上点掉。建议把典礼文件夹加进 PowerPoint 的“受信任位置”。
- 投影到哪个屏幕由 PowerPoint 自己的设置决定（幻灯片放映 → 监视器）。VLC 全屏会出现在 VLC 窗口当时所在的屏幕。
- 出问题时请看 exe 旁边的 `ppt-presenter.log`。
